## 仓库结构

```
chapters/   章节源稿（每章一个独立 Markdown 文件，便于单章迭代）
figures/    全书插图（SVG 矢量格式）
scripts/    构建脚本（合并章节并生成 PDF）
```

## 构建

合并书稿与 PDF 由脚本自动生成，请勿直接编辑根目录的合并文件：

```bash
# 依赖：pandoc（Markdown -> HTML）、Microsoft Edge（headless 打印 PDF）
python scripts/build.py
```
