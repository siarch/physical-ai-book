# 物理AI：从自动驾驶到具身智能

一本关于**物理人工智能（Physical AI）**的技术书籍。全书以自动驾驶与具身智能（人形机器人）两大载体为主线，系统梳理**算法范式、数据引擎、硬件底座（电子电气架构、计算芯片与机电躯体）、安全体系**四条技术主线的软硬协同演进与前沿实践。

## 仓库结构

```

figures/    全书插图（SVG 矢量格式）
scripts/    构建脚本（合并章节并生成 PDF）
```

## 构建

合并书稿与 PDF 由脚本自动生成，请勿直接编辑根目录的合并文件：

```bash
# 依赖：pandoc（Markdown -> HTML）、Microsoft Edge（headless 打印 PDF）
python scripts/build.py
```
